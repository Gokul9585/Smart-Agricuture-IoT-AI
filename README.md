Smart Agriculture and Irrigation System Using IoT with AI Techniques

Project Overview

This project integrates Internet of Things (IoT), Artificial Intelligence (AI), and automated irrigation to support smart and sustainable agriculture.

Key Features

- Real-time soil moisture, temperature and humidity monitoring.
- AI-based crop recommendation.
- Plant disease detection using leaf images.
- Automatic irrigation using four water-level sensors.
- ESP8266-based sensor data collection.
- Cloud-based data transmission and monitoring.
- Pump flow monitoring and fault detection.
- Mobile application for farmer alerts and manual control.

Technologies Used

- Internet of Things (IoT)
- Artificial Intelligence (AI)
- ESP8266
- Soil Moisture Sensor
- DHT Sensor
- Water-Level Sensors
- Flow Sensor
- Cloud Connectivity
- Mobile Application
